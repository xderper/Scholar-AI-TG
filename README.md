# Scholar-AI-TG - Education Telegram Bot

## Описание проекта
Scholar-AI-TG - это Telegram бот для помощи в решении задач. Бот использует современные AI технологии для анализа и решения физических задач, представленных как в текстовом, так и в изображенном виде.

## Функциональность
- Решение физических задач по тексту
- Обработка изображений с физическими задачами (GPT-4o)
- Форматирование ответов с использованием HTML и Unicode символов
- Интуитивный интерфейс с клавиатурой для выбора типа ввода
- Команды /start и /help для начала работы
- Информационный раздел с описанием функционала

## Технические особенности
- Использование OpenAI API для анализа и решения задач
- Docker-контейнеризация для простой установки и развертывания
- Система управления состояниями для корректной работы с диалогами
- Автоматическое форматирование ответов для Telegram

## Установка и запуск
1. Установите Docker и Docker Compose
2. Скопируйте `.env.example` в `.env` и заполните необходимые переменные окружения
3. Запустите контейнеры:
```bash
docker-compose up -d
```

## Требования
- Python 3.8+
- Docker и Docker Compose
- OpenAI API ключ
- Telegram Bot API ключ

## Структура проекта
```
bot/
├── handlers/           # Обработчики сообщений и команд
├── utils/             # Утилиты и вспомогательные классы
├── format.py          # Форматирование ответов для Telegram
└── requests.py        # Обработка запросов к AI
```

## Безопасность
- Файлы с конфигурацией (.env) не должны коммититься в репозиторий
- API ключи должны храниться в переменных окружения
- Всегда проверяйте, что чувствительные данные не попадают в историю Git
